# Product Images Directory

Replace any image in this folder with your actual product photo using the exact same filename.

Supported filenames used by sample products:
- `hero-fan.jpg`: Main homepage hero ceiling fan photo (recommended 16:9 or 1200x800)
- `ceiling-fan-01.jpg`: Standard ceiling fan product image (4:3 or 1:1, e.g. 800x800)
- `ceiling-fan-02.jpg`: Secondary ceiling fan photo / angle
- `table-fan-01.jpg`: Table fan product photo (4:3 or 1:1, e.g. 800x800)
- `table-fan-02.jpg`: Secondary table fan photo / angle
- `pedestal-fan-01.jpg`: Pedestal fan product photo (4:3 or 1:1, e.g. 800x800)
- `pedestal-fan-02.jpg`: Secondary pedestal fan photo / angle

## Instructions:
1. Ensure your product image is crisp and well-lit on a clean white or neutral background.
2. Optimize file size (under 500KB per image recommended for fast loading across India).
3. Name your file matching the filename above or update `/data/products.ts` with your new image path.
